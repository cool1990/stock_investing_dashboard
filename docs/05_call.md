# 05 电话会

- 路由：`#/MU/call`（默认最新一场），`#/MU/call/FQ3-26`
- 设计稿：`docs/design/call-mockup.dc.html`
- 通用约定：`01_common.md`

## 1. 目的

用 5 分钟看懂一场 1 小时的电话会：
1. 管理层讲了什么，分成业绩回顾和未来展望两部分；
2. 与上一场相比，哪些表述是**新增的**，哪些**措辞发生了变化**；
3. 分析师在追问什么，管理层怎么回答；
4. 需要时能一键定位到原文，并可以跨所有场次做全文搜索。

### 2.1 左侧栏

- **会议列表**按时间倒序排列。每项显示：财期（加粗）、日期 · 原文来源状态。状态有四种：「官方回放转写」「原文可查」「第三方文字稿」「解析中」。当前场次用 `--sel-bg` 底色，左侧加 2px `--up` 内阴影。
- **搜索框**：在全部会议的原文中做全文匹配（中英文都可以）。结果按季度分组列出命中段落，命中词高亮；点击后跳到该场的「原文」tab，并定位到对应段落。
- 底部说明：「共 N 场（FQ1-22 起）。搜索会在全部会议的原文中匹配，并按季度列出命中段落。」
- 宽度 < 900px 时，左侧栏变为顶部的下拉选择。

### 2.2 会议头部

- H2：「FQ4-26 财报电话会议」。副行：美东日期和时间 · 时长。
- **参会高管**：每人一个圆形头像，里面是姓名首字母（例如 SM），旁边是姓名和职务（中文）。职务的中文翻译写在 `config/companies/<T>.yaml` 的 `executives:` 中。
- **三个外链**：准备稿 PDF（官网）、Webcast 回放（官网）、第三方文字稿（校对用）。URL 缺失时显示为灰色不可点。

### 2.3 Tab 与对比开关

- Tab：管理层发言 / 分析师问答 / 原文。
- 「显示与上季（FQ3-26）的表述变化」开关默认开启：
  - 开启时，显示「新增 / 变化」标签和「上一场：…」引文；
  - 关闭时，两者都隐藏；
  - 没有上一场时，开关禁用。

### 2.4 本场给出的指引

- 卡片标题为「本场给出的指引 · FQ1-27」，右侧有链接「在财报解读中查看与共识对比 →」。
- 内部用网格排列各项指引，每项显示标签和值。例如：营收 $61.5B ±1.5B；毛利率 NG / GAAP 86.25% / 85.95%；Opex NG / GAAP $2.06B / $2.31B；EPS NG $38.15 ±1.00；EPS GAAP $37.84 ±1.00；净 Capex ≈ $11.5B。
- 数据与 `03` 的指引同源，都来自新闻稿。

### 2.5 管理层发言（tab 1）

- **按讲话人分卡**：CEO 一张、CFO 一张。
- 卡片头部包括：头像首字母、姓名、职务，以及「相对上一场：…」一句总结（AI 生成）。
- 卡片内容分**两栏**：「业绩回顾与变动分析」和「未来展望（含指引）」。
- 每一栏是要点列表。每条要点的格式是 `主题：内容`，主题加粗，例如「长约：已签 26 份 SCA，预计覆盖 2030 年前超过 35% 的收入。」
  - 可选标签：`新增`（蓝底）或 `变化`（橙底）；
  - 有「变化」标签时，下方显示「上一场：…」（灰色小字，引自上一场原话）；
  - 每条末尾有「定位原文」链接，跳到原文 tab 对应的时间戳或段落。
- 要点数量：每人每栏 3–8 条，按原文顺序排列。

### 2.6 分析师问答（tab 2）

- **主题筛选标签**：全部 10、资本回报 2、HBM 2、Capex 2、毛利率 1、价格 / 周期 1、SCA 1、NAND 1。数字是问题数；点击后过滤。主题由 AI 聚类，主题词表维护在 `config/companies/<T>.yaml` 的 `call_topics:` 中，AI 只能从词表里选。
- 每位分析师一组：
  - 头部：分析师姓名、机构、时间戳；
  - 内容是若干个回合：「提问 / 追问」标签、问题（中文摘要）；「回答 · 发言人」、回答（中文摘要）。
- MU FQ4-26 有 5 位分析师，来自设计稿：Timothy Arcuri（UBS）、C.J. Muse（Cantor Fitzgerald）、Vivek Arya（BofA Securities）、Krish Sankar（TD Cowen）、Harlan Sur（JPMorgan）。

### 2.7 原文（tab 3）

- **来源切换**：官方回放转写 / 准备稿 PDF / 第三方文字稿。只显示有内容的来源。
- **「显示中文对照」开关**：开启后，每段英文下面显示中文（AI 翻译，标注「机器翻译」）。
- 每一段显示：时间戳、发言人、职务 / 机构，然后是英文原文和中文翻译。
- 段落有锚点 `#p{n}`，供「定位原文」跳转使用。
- **转写校对说明**放在页面底部，例如：「转写校对：第三方文字稿写作 Timothy Curie，已按券商名单校正为 Timothy Arcuri（UBS）。」

## 3. 数据来源

| 数据 | 来源 | 方法 | 可靠性 |
|---|---|---|---|
| 准备稿（Prepared Remarks） | 公司 IR 网站的 PDF | `pdfplumber` 提取文本，按讲话人分段 | 稳定 |
| 问答全文 | 第三方公开文字稿（如 Motley Fool、MarketBeat 的 transcript 页面） | HTML 解析为 `[{speaker, role, text}]` | 有条件 |
| 官方回放 | IR 网站的 webcast 链接 | 本期只保存链接；音频转写为可选扩展（例如用 Whisper 在本地或 Actions 中运行，耗时较长） | 有条件 |
| 会议时间、时长 | IR 网站的活动页，或文字稿头部 | 解析 | 有条件 |
| 高管名单与职务 | 文字稿的 Participants 段落，加 `executives:` 配置 | 解析加配置 | 稳定 |
| 分析师名单 | 文字稿，加 `config/analysts.yaml` 校正表 | 解析加校正 | 稳定 |
| 要点、标签、主题聚类、问答摘要、翻译 | AI（默认在 Cursor 中手动处理任务包；预留 DeepSeek API） | 见第 4 节和 `01_common.md` 第 7.5 节 | 不稳定 |
| 本场指引 | 新闻稿（03） | 表格解析 | 稳定 |

**获取时序**：
- 财报日当晚（`earnings-night.yml`）：抓新闻稿和准备稿 PDF。
- T+1：抓第三方文字稿。
- 都拿到后生成 AI 任务包，等待在 Cursor 中处理。
- 状态标签由数据决定：没有任何原文时显示「解析中」，只有准备稿时显示「原文可查」，依此类推。

**版权**：第三方文字稿只用于内部检索和对齐。页面上的「原文」tab，以准备稿和官方来源为主；第三方来源只展示必要的片段，并链接到原页面。

## 4. AI 处理流程

以下每一步都对应一个 AI 任务包，由 `ai_prepare.py` 生成，在 Cursor 中处理（手动模式），见 `01_common.md` 第 7.5 节。分段（第 1 步）和校验（第 7 步）由脚本完成，不需要 AI。

1. **分段**：把原文切成段落，每段有唯一 id（`p12`），记录发言人和时间戳（如果有）。
2. **要点抽取**（`prompts/call_points_vN.md`）：
   - 输入：某位讲话人的全部段落，以及该公司的主题词表。
   - 输出：`[{part: "review"|"outlook", topic, text_zh, src: ["p12","p13"]}]`。
   - 要求：中文、一句话、不加评价；**数字只能照抄原文**。
3. **与上一场对比**（`prompts/call_diff_vN.md`）：
   - 输入：本场要点，加上一场同一讲话人的全部段落。
   - 输出：每条要点的 `tag ∈ {新增, 变化, 不变}`；如果是「变化」，给出 `prev_quote` 和 `prev_src`。
   - 规则：上一场没有提到这个主题 → 新增；同主题但措辞或方向不同 → 变化；否则 → 不变（不显示标签）。
4. **讲话人总结**：「相对上一场：…」，一句话，只能基于第 3 步的结果。
5. **问答**：
   - 把文字稿中的 Q&A 部分切成「分析师 → 管理层回答」的回合，追问作为同一分析师下的新回合；
   - 每个回合输出中文摘要，并从词表中选一个主题。
6. **翻译**：逐段翻译，输出时标注 `machine_translated: true`。
7. **校验**：
   - 每条输出都必须有 `src`，并且所指的段落存在；
   - 输出中出现的每个数字，都必须在所引用的段落中出现（容许 $54.2B 与 54.2 billion 这样的等价写法）；
   - 不满足就丢弃，并记录到 `_status`。

## 6. 注意事项

1. **分析师姓名校正**：第三方转写常常拼错人名。`config/analysts.yaml` 维护「错误写法 → 正确姓名 + 机构」的对照，每次校正都写入 `corrections`。
2. **上一场的对齐**：「上一场」指同一公司按时间排序的前一场财报电话会，不包括投资者日或行业会议。
3. **没有上一场时**（例如第一场 FQ1-22）不打标签，对比开关禁用。
4. **AI 摘要不能夹带评价**（如「表现亮眼」）。prompt 中要明确禁止，并在校验中过滤常见的评价词。
5. **时间戳**：只有官方回放转写才有可靠的时间戳。第三方文字稿没有时间戳时显示 `[mm:ss]`，定位改用段落锚点。
6. **工作量控制**：AI 只处理新的场次。历史场次可以分批在 Cursor 中回填，例如每次一个季度；结果按输入哈希记录，不重复处理。
