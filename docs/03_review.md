# 03 财报解读（个股默认页）

- 路由：`#/MU`（默认显示最新一期），`#/MU/review/FQ3-26`（查看历史某一期）
- 设计稿：`docs/design/main-mockup.dc.html`
- 通用约定：`01_common.md`

## 1. 目的

针对一期财报，回答四个问题：
1. **结果好不好**：和发布前共识、和上季给出的指引比较。
2. **为什么**：把变化拆解到量、价、费用、现金流。
3. **管理层怎么看下一步**：本季给出的指引，以及表述上的变化。
4. **接下来盯什么**：本期关注事项，汇总到观察池的「待验证跟踪项」。

页面上的**数字全部来自结构化数据**。「总结」「为什么」「原因」这类文字由 AI 生成，每条都附原文出处。

### 2.1 总结卡

- **结论标签**：用 `Tag` 组件，可能的值有「超预期 / 符合预期 / 不及预期 / 好坏参半」。判定规则写在配置中，默认规则如下：
  - 收入和 EPS 都 ≥ +2%，且下季指引中值 ≥ 共识 → 超预期；
  - 两者都在 ±2% 之内 → 符合预期；
  - 两者都 ≤ −2% → 不及预期；
  - 其他情况 → 好坏参半。
- **数字行**：由模板拼接，**不用 AI**：`收入 {rev_surp} · EPS {eps_surp}（vs 发布前共识）· 下季指引{高于/低于}共识 {x–y}%`。
- **总结段落**：AI 生成，2–3 句。输入只包括本页已算好的数字，加上新闻稿和准备稿的原文。
- **本期关注**：最多 3 条，每条是「标题：一句话」。由 AI 起草，人工在 `config/notes/<T>.yaml` 中确认、修改或标记已解决；**只有确认过的条目才显示**。未确认时显示「待确认」灰色标记。

### 2.3 拆解区

**指标选择条**共 9 项：营收、毛利率、营业利润率、净利润率、摊薄 EPS、净 Capex、经营现金流、自由现金流、订单（代理）。
- 每一项都是小卡片，显示：标签、数值、一行变化（例如营收显示「$54.23B，同比 +379% · 环比 +31%」；订单代理显示「≈ $150B，RPO · 预付款 $12.9B」）。
- 小卡片的选中状态与上方主卡联动。

**标题行**：指标名、口径、单位；右侧有两组切换：「历史 / 结构」和「季度 / 年度」。

**历史视图**：
- 柱状图：默认显示最近 5 期，最新一期用 `--up`，其余用 `--hist-bar`；柱顶标注数值；缺失的期显示 2px 灰条，并标注 `[ ]`。
- 叠加两条折线：同比（`--up-dark`，标签在点的上方）和环比（`--down`，标签在点的下方）。
- **变化率超过 400% 的点在图上封顶显示**，标签仍写真实值并加「↑」。零线用虚线。
- 下方是数据表：行为期间、数值、同比、环比；年度视图没有环比行。
- 底部是历史注释，例如「GAAP 毛利率：FQ4-26 86.8% · …」，或「变化率超过 400% 的点在图上封顶显示」。
- 期数范围：提供「最近 5 期 / 最近 12 期 / 全部（FQ1-22 起）」。

**结构视图**：
- 每个指标对应 1–2 个子面板。子面板包括标题、来源标签（例如「FQ4-26 新闻稿」），以及若干行。
- 每行包括：标签、数值、副文本（例如「占 33.2% · 同比 +1042% · 环比 +56.2%」）、比例条（宽度 0–100%，颜色用于区分层级）。
- 子面板底部有一句解读，由 AI 生成并附出处。

**子面板定义写在 `companies/<T>.yaml` 的 `metrics:` 中**，因为不同行业的指标不同。MU 的定义如下（来自设计稿）：

| 指标 | 子面板 1 | 子面板 2 |
|---|---|---|
| 营收 | 按业务单元（CDBU / CMBU / MCBU / AEBU：金额、占比、同比、环比） | 按技术 · 量价（DRAM / NAND 金额与占比；出货量和价格的环比区间来自准备稿） |
| 毛利率 | 收入 → 销售成本 → 毛利（GAAP） | 业务单元营业利润率（作为毛利率的代理），与上季对比 |
| 营业利润率 | 收入 → 营业利润（各项费用占收入 %、环比） | 营业费用历史（研发、SG&A 最近 4 季） |
| 净利润率 | 营业利润 → 净利润（营业外收支加所得税） | GAAP vs Non-GAAP 净利润 |
| 摊薄 EPS | GAAP → Non-GAAP 调节（股权激励、诉讼、债务清偿 / 税等） | EPS = 净利润 ÷ 摊薄股数 |
| 净 Capex | 产能项目时间表（准备稿） | Capex 指引（下季、上半年、全年） |
| 经营现金流 | 构成：净利润、折旧摊销、客户预付款、营运资本 | — |
| 自由现金流 | FCF 推导：经营现金流 − 净 Capex，再剔除客户预付款 | — |
| 订单（代理） | 需求可见度：RPO、客户财务承诺、非流动合同负债 | 合同覆盖度：已承诺产出比例、SCA 覆盖率 |

配置示例：

```yaml
metrics:
  rev:
    label: 营收
    basis: GAAP · $B
    series: { source: financials, field: revenue }
    struct:
      - title: 按业务单元
        source: release.segments          # 新闻稿分部表
        rows: from_segments(revenue)
      - title: 按技术 · 量价
        source: [release.tech_split, remarks.price_volume]
  order:
    label: 订单（代理）
    basis: 非流动客户合同负债 · $B
    series: { source: financials, field: contract_liab_noncurrent }
    note: 美光不公布订单或 backlog；以下为代理指标，不等于订单，不能相加。
```

### 2.4 指引表（区块 2）

- 列：指标、数值、隐含环比、隐含同比、较共识。
- 分组标题行（`--row-sec` 底色、12px、字重 700、`--up-dark`）有三类，**公司没有给出的分组不显示**：
  1. **财务目标**：收入、毛利率、营业费用、EPS、Capex、税率等，分为「下季度 · FQ1-27」和「明年 · FY27」两段；
  2. **经营目标**：出货、产能、份额、里程碑；
  3. **订单与可见度**：订单、backlog、RPO、长约覆盖。
- 分组定义写在 `companies/<T>.yaml` 的 `guidance_groups:` 中。
- **计算规则**：
  - 隐含环比 = 指引中值 ÷ 本季实际 − 1；
  - 隐含同比 = 指引中值 ÷ 去年同期实际 − 1；
  - 比率类用 pp；
  - 较共识 = 指引中值 ÷ 发布前（下季）共识 − 1。
- 文字型指引（例如「每季环比增长，创纪录」）原样显示在数值列，其他列显示 `—`。
- 「推算」项（例如「FY27 Opex 较 FY26 增加约 $2.5B → ≈ +33%」）要标注「推算」，`title` 中显示计算基数。
- 表格下方是「管理层给出的原因」，由 AI 从准备稿中摘取，并附原句链接。

## 3. 数据来源

| 数据 | 来源 | 方法 |
|---|---|---|
| GAAP 利润表、资产负债表、现金流量表 | EDGAR XBRL（见 04） | 结构化 |
| Non-GAAP 毛利率、营业利润、净利润、EPS | 8-K EX-99.1 新闻稿中的调节表 | HTML 表格解析，并做**数字反查** |
| 业务单元分部 | 新闻稿中的分部表；10-Q 的分部附注作为校验 | 表格解析 |
| 技术拆分（DRAM / NAND）、量价区间 | 准备稿 PDF（IR 网站） | 规则匹配加 AI 抽取，必须附原句 |
| 指引 | 新闻稿中的「Business Outlook」表 | 表格解析；区间、中值、± 都要保存 |
| 文字型指引、产能里程碑、RPO、SCA | 准备稿和电话会问答 | AI 抽取，必须附原句 |
| 发布前共识 | 共识快照（见 06） | 发布前最后一份快照 |
| 管理层表述、分析师提问 | 05 电话会的解析结果 | 同源 |

**新闻稿的获取方式**：
1. 通过 EDGAR submissions 找到该财报日的 8-K（item 2.02）；
2. 打开 filing index，找到 `EX-99.1`；
3. 把 HTML 保存到 `data/raw/<T>/<FQ>/press.html`。

**解析要求**：
- 先按表格结构解析（`pandas.read_html` 加表头规则）。
- 每个解析结果都要附带「表名 + 行名 + 列名」。
- 解析完成后做反查：数值必须在原 HTML 文本中能找到对应的格式化字符串（例如 54,229）。
- 反查失败的项标记为 `unverified`，页面显示「未披露」。

## 5. 计算口径

- 同比、环比、n.m.、pp 的规则见 `01_common.md` 第 6 节。
- **较共识** = 实际值 ÷ 发布前共识 − 1。
- **相对指引** = 实际值 ÷ 上季给出的指引中值 − 1。
- **毛利率**：卡片和拆解默认用 Non-GAAP（与指引口径一致），历史注释中同时给出 GAAP。
- **自由现金流（公司口径）** = 经营现金流 − 净 Capex。净 Capex = 购建 PP&E − 政府补贴与合作方出资。
- **剔除预付款后的 FCF** = FCF − 本季客户合同负债的增加额。在页面上标注「推算」。
- **订单代理**：非流动客户合同负债的季末余额。必须附注「不等于订单」。
- **摊薄股数**：从 XBRL 的 `WeightedAverageNumberOfDilutedSharesOutstanding` 取得；没有时用净利润 ÷ EPS 推算，并标注「推算」。

## 6. 注意事项

1. **口径标注不能省**：每张卡、每个图的标题都要写明 GAAP、Non-GAAP 或公司口径。
2. **指引的基数**：隐含环比的基数是本季实际值，隐含同比的基数是去年同期实际值；毛利率用同一口径（Non-GAAP）。
3. **上一季的指引**要从上一季的新闻稿中解析，存到 `releases/<T>/<FQ>.json` 的 `guidance_for_next` 字段，供本季计算「相对指引」。
4. **AI 内容**：总结、为什么、子面板解读、原因、表述对比都必须带 `refs`。前端点击后能展开原句，并链接到原文。没有 refs 的 AI 输出不展示。
5. **AI 不产生数字**：AI 文本中出现的每个数字，都要能在输入数据或原文中找到，找不到就丢弃这一条（见 `01_common.md` 第 7.5 节）。
6. **AI 未处理时**：所有 AI 文本位置显示「AI 解读待生成」（灰色），数字部分照常显示（流程见 `01_common.md` 第 7.5 节）。
7. **期间切换**：历史各期都可以查看。还没有准备稿或电话会的旧期，「互动」区显示「无电话会解析」。
8. **增速封顶**：只影响图上的显示位置，标签和表格都显示真实值。
