# 07 股价反应

- 路由：`#/MU/price`
- 设计稿：`docs/design/price-mockup.dc.html`
- 通用约定：`01_common.md`

## 1. 目的

复盘每次财报发布后市场是怎么定价的，回答三个问题：
1. 这次涨跌了多少？和历史比算大还是小？和期权隐含的波动相比如何？
2. 「超预期」和「指引」，哪个更能解释股价反应？
3. 有没有「超预期却下跌」的情况？当时市场在交易什么？

### 2.1 窗口切换

窗口有三个选项：盘后 / 次日 / T+5。切换后，KPI 卡的标题和数值随之变化（例如「本次（FQ4-26）次日」）。逐次复盘表固定显示所有列，不受影响。

### 2.2 KPI 卡

| 卡 | 主值 | 副行 |
|---|---|---|
| 本次（最新一期）{窗口} | 涨跌幅 | 反应日 YYYY-MM-DD（盘后发布 → 次日） |
| 近 8 次平均 {窗口} | 平均涨跌幅（算术平均） | 上涨 x 次 / 8 |
| 实际波动 vs 期权隐含波动 | 平均绝对涨跌 / 平均发布前隐含波动 | 平均绝对涨跌 / 发布前隐含 |
| 「超预期却下跌」次数 | x / 8 | 例如「近 8 季 EPS 全部超预期」（由数据生成） |

### 2.3 股价走势图

- 时间范围：1 年 / 2 年 / 全部（2021Q4 起）。
- 用日线收盘价画折线（`--ink-2`，1.5px）。
- 每个财报日画一条竖直虚线（`--hist-bar`），顶部放一个 18px 的蓝色圆形「E」标记，底部标注季度名（等宽字体、10px）。
- 悬停 E 标记时显示 tooltip：季度、发布日、EPS 和收入超预期幅度、次日涨跌；点击后跳到 `#/MU/review/<FQ>`。
- x 轴标注半年刻度；y 轴显示价格（$）。
- 鼠标在图上移动时显示十字线和当天收盘价。

### 2.4 逐次复盘表

| 列 | 说明 |

| 季度 | FQ4-26 |

### 2.5 散点图

- 每个点代表一次财报；横轴可在 EPS 超预期 / 收入超预期 / 指引 vs 共识之间切换；纵轴是次日涨跌（跟随窗口切换）。
- 画出 0 线（横向和纵向）；最新一次的点用 `--up` 并标注季度名，其他点用 `--hist-bar`。
- 悬停时显示季度和两个数值。
- 底部用一行小字显示简单线性回归的斜率和 R²（点数 ≥ 6 时才显示），并注明「样本少，仅供参考」。

## 3. 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 日线 OHLC | yfinance `history(period="max", auto_adjust=False)`；Stooq CSV 作备份 | 价格用**未复权**的收盘价计算涨跌（单日涨跌不受影响）；走势图用复权价，避免拆股造成断点 |
| 发布日与时段 | 8-K item 2.02 的提交时间，加 `companies/<T>.yaml` 的 `release_timing` | MU 固定在盘后发布 |
| 盘后 / 盘前价格 | yfinance `history(interval="1m" 或 "5m", prepost=True)` | **只能回溯约 30–60 天**，所以必须由 `earnings-night.yml` 在财报日当晚（美东 20:00 后）快照，存入 `events/<T>.json` |
| 期权隐含波动 | yfinance `option_chain(最近到期日)` | 在发布前一日收盘后快照：平值 call 与 put 的中间价之和 ÷ 股价。选择**发布日之后最近**的到期日 |
| 超预期、指引 vs 共识 | 06 的 history 数据、03 的 guidance 数据 | 同源 |
| 复盘笔记 | AI 草稿加人工校准 | 输入：超预期、指引 vs 共识、涨跌幅、电话会要点（05） |

## 5. 计算口径

- **基准价**：发布前最后一个常规交易时段（09:30–16:00 美东）的收盘价。盘后发布时取发布当日收盘，盘前发布时取前一交易日收盘。
- **次日涨跌** = 反应日收盘 ÷ 基准价 − 1。
- **T+5** = 反应日后第 5 个交易日的收盘 ÷ 基准价 − 1（反应日本身算 T+0）。
- **盘后涨跌** = 发布当晚 20:00 美东前最后一笔成交价 ÷ 基准价 − 1。没有快照的历史期，用「次日开盘 ÷ 基准价 − 1」近似，并标注「近似」。
- **隐含波动（单次财报的隐含涨跌幅）** = (ATM call 中间价 + ATM put 中间价) ÷ 现价。ATM 取最接近现价的行权价。
- **超预期却下跌**：EPS 超预期 > 0 且所选窗口的涨跌 < 0。
- **实际波动 vs 隐含**：近 8 次的平均 |次日涨跌|，对比近 8 次的平均隐含波动。只用两者都有数据的期数，并注明 n。

## 6. 口径说明区（页面静态文字）

1. **时段**：盘后发布（美东 16:00 后）→ 反应日为下一交易日；盘前发布（09:30 前）→ 反应日为当日。美光固定在盘后发布。
2. **盘后 / 盘前**：免费分钟线只能回溯约 30–60 天，所以从现在起，每个财报日当晚记录盘后价；更早的历史用「次日开盘跳空」近似。
3. **隐含波动**：发布前一日、最近到期的平值跨式期权价格 ÷ 股价，同样需要提前快照。
4. **复盘笔记**：AI 预填一句「市场在交易什么」，由你来校准。

## 7. 注意事项

1. **交易日历**：使用 `pandas_market_calendars`（NYSE）判断交易日和半日市，不要简单地跳过周末。
2. **拆股**：计算单次涨跌时用同一天的未复权价格，不受拆股影响；走势图用复权价。
3. **期权快照的时机**：必须在发布**之前**的收盘后进行。错过了就留空，不能事后补。
4. **复盘笔记**作为 AI 任务包生成，在 Cursor 中处理（见 `01_common.md` 第 7.5 节）。AI 输入只能包括本页数字和电话会要点，输出控制在一句话、不超过 40 字，并且必须引用至少一个数字或要点。
5. 「近 8 次」统计时，如果某一期缺少窗口数据，就从可用的期数中统计，并在副行写明实际的 n。
